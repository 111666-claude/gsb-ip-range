# ip-range

IP 段规范化与合并（最小 CIDR 集合），只用 Python 标准库。

```
python3 -m iprange.cli --add 10.0.0.0/25 --add 10.0.0.128/25 --list
python3 -m iprange.cli --add 10.0.0.7/24 --list
python3 -m iprange.cli --add 10.0.0.0/24 --contains 10.0.0.7
python3 -m unittest discover -s tests -v
```

## 口径（README 为准）

- **相邻与重叠要合并成最小 CIDR 集合**：`--add 10.0.0.0/25 --add 10.0.0.128/25 --list` 按口径只输出一行
  `10.0.0.0/24`；现在只去掉重复段，给两行。
- **主机位要清零**：`--add 10.0.0.7/24 --list` 按口径是 `10.0.0.0/24`，现在照抄成 `10.0.0.7/24`。
- **按数值排序**：`--add 10.0.0.10/32 --add 10.0.0.2/32 --list` 按口径是 `10.0.0.2/32` 在前，
  现在按字符串比，给 `10.0.0.10/32` 在前。
- 合并规则：重叠或相邻的段合成最小 CIDR 集合；结果里任意两段不相交；IPv4 段排在 IPv6 段前面。
- 幂等：同一个段加多次、或调换 `--add` 的顺序，结果一致。
- `--contains`：命中给 `yes`，否则 `no`；10 万段时不许为每个段重新构造网络对象。
- 输入：`--add` 是 `地址/前缀`；前缀越界、地址非法、缺 `/` 都要报错并指出是第几个 `--add`。
- 规模：10 万个段（`/8` 与 `/32` 混排）合并，内存 O(段数)，不许把段展开成地址列表。
- 对照自证：能逐地址展开的小段（`/24` 及更短）与「集合暴力并集」对照，差异必须为 0。

## 现在的行为

- `parse_range` 直接 `int(prefix)`，前缀越界与非法地址抛 Python 原始异常；主机位不清零。
- `merge` 只做完全重复的去重，相邻段（两个 `/25`）与重叠段都不合并。
- `merge` 用 `sorted(..., key=format_range)`，`10.0.0.10/32` 排在 `10.0.0.2/32` 前面。

## 计划新增的能力

```
--add CIDR      加入一个段，可重复
--list          打印合并后的 CIDR 列表
--contains 地址 判断是否被覆盖
```

## 输出

```
10.0.0.0/24
```
